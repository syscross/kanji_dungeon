# KANJI DUNGEON 【漢字地獄】

A dark-fantasy kanji roguelike judged by an AI game master — twelve gaols, **6,355 kanji** (Kanken Level 10 to Level 1). Draft a deck of kanji, choose your path by sign, and fight with nothing but their meanings.

- **Play Live:** [https://kanjidungeon.vercel.app](https://kanjidungeon.vercel.app)
- **Zero setup:** Trial mode works out of the box; a fully offline judge works with no AI at all.
- **BYOK (Bring Your Own Key):** Gemini, Anthropic Claude, OpenAI, DeepSeek, Groq, xAI, OpenRouter, or any OpenAI-compatible endpoint — called directly from the browser, keys stay in `localStorage`.
- **No build step:** plain HTML/CSS/JS. See `HANDOVER.md` for the file map and judging contract.
